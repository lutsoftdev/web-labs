# Практична 1 — Клієнт → бекенд → БД

## Запуск

```bash
cd 01-client-backend-db
npm install
npm run init-db
npm start
```

Відкрий http://localhost:3000 → кнопка **Load items**.

## Що здано

- Express API: `GET /items`
- SQLite таблиця `items (id, name)` з тестовими товарами
- HTML-клієнт із кнопкою Load items
