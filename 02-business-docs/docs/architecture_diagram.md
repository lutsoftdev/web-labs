# Пояснення блоків діаграми

Див. також `architecture_diagram.svg` (можна відкрити в браузері або зберегти як PNG).

| Блок | Що це | Аналогія |
|------|-------|----------|
| Client | Браузер користувача | Вітрина магазину |
| Backend | Express API | Продавець за прилавком |
| Database | SQLite | Складський журнал |
| Auth | Майбутній вхід | Перепустка в клуб |
| Notifications | Майбутні листи/пуші | SMS «замовлення готове» |
| Payments | Майбутня оплата | Каса |

Потік зараз: **Client → Backend → Database**.
