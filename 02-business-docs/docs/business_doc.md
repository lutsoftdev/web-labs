# SoftShop — бізнес-документ

## Назва та опис
**SoftShop** — невеликий онлайн-магазин електроніки для студентів.
Користувач переглядає каталог товарів, додає їх у кошик і оформлює замовлення.
Система зберігає товари, замовлення та базову інформацію про покупця.

Мета першої версії — простий каталог і замовлення без складної логістики
та без реальної банківської оплати (оплата навчальна).

## Користувачі (ролі)
| Роль | Що робить |
|------|-----------|
| Покупець | Переглядає товари, створює замовлення |
| Адмін (майбутнє) | Додає/редагує товари |
| Система | Зберігає дані, віддає API |

## Основні сценарії (use cases)
1. Покупець відкриває каталог і бачить список товарів.
2. Покупець створює замовлення з кількох товарів.
3. Покупець переглядає статус свого замовлення.
4. Адмін додає новий товар у каталог (майбутнє).
5. Система повертає помилку, якщо товару немає в наявності.

## Функціональні вимоги
- Перегляд списку товарів
- CRUD для товару (через API)
- Створення замовлення
- Перегляд замовлення за id

## Нефункціональні вимоги
- Відповідь API зазвичай < 500 мс локально
- Дані не втрачаються після перезапуску (SQLite)
- Зрозумілий інтерфейс для новачка
- Єдиний формат помилок API

## Обмеження (чого НЕ робимо)
- Немає реальної оплати карткою
- Немає доставки кур'єром
- Немає мобільного додатку
- Немає багатомовності
