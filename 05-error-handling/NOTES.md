# Пояснювальна — Практична 5

## Зміст
1. Ідемпотентність
2. Ретраї / backoff / таймаут
3. X-Request-Id і 429
4. Degraded mode
5. Фрази

## 1. Ідемпотентність = «натиснув двічі — оплатив один раз»
Idempotency-Key — унікальний квиток запиту. Сервер пам'ятає: цей квиток уже обслуговували → повертає той самий результат, без другого замовлення.

## 2. Ретраї
Якщо каса «зависла» (5xx) — клієнт чекає трохи довше і пробує знову (backoff + jitter, щоб не бити всі разом).
Таймаут (AbortController) — «якщо довше N мс — скасовую очікування».

## 3. X-Request-Id
Номер посилки. За ним шукають запит у логах.
429 + Retry-After — «черга повна, повернись через X секунд».

## 4. Degraded mode
Після кількох збоїв сайт показує банер «перевантажено» і блокує кнопки — чесна поведінка замість вічного спінера.

## 5. Фрази
- «Повтор з тим самим ключем не створює дубль.»
- «Ретрай лікує тимчасові збої; ідемпотентність робить ретрай безпечним.»
