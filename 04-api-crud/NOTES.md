# Пояснювальна — Практична 4

## Зміст
1. Моноліт vs мікросервіси
2. Шари api / service / domain
3. OpenAPI і DTO
4. Фрази

## 1. Моноліт = один магазин під одним дахом
Усі відділи в одній будівлі. Мікросервіси — окремі будівлі з кур'єрами між ними.
Для SoftShop і однієї людини моноліт простіший → ADR 0001.

## 2. Шари (як конвеєр)
- api — каса (приймає запит)
- service — менеджер (перевіряє і вирішує)
- domain — правила товару (ціна, назва)

## 3. OpenAPI
Це «меню ресторану» для API: які страви (endpoints) і який вигляд порції (DTO).
Swagger Editor показує меню красиво.

## 4. Фрази
- «CRUD — Create Read Update Delete.»
- «DTO — посилка для передачі даних, без бізнес-логіки.»
- «ADR — записка: чому так вирішили.»
