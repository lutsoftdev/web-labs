# ADR 0001: Architecture style

- Status: Accepted
- Date: 2026-11-15

## Context
Команда маленька (1 людина), строк короткий, SoftShop — навчальний магазин.
Досвід розподілених систем обмежений.

## Decision
**Модульний моноліт** зараз (один Express-застосунок з шарами api / service / domain).

## Alternatives
- Мікросервіси з першого дня — зайва складність для CRUD каталогу.

## Consequences
+ Простіший деплой і дебаг
+ Одна БД / одне сховище
− Пізніше складніше масштабувати окремі частини незалежно

## Умови перегляду
Коли з'являться окремі команди або різні цикли релізу для Catalog / Orders / Payments.
