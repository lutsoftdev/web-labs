# Пояснювальна — Практична 3 (DDD)

## Зміст
1. Що таке домен
2. Bounded context
3. Ubiquitous Language
4. Фрази для захисту

## 1. Домен = «світ бізнесу»
Онлайн-магазин — це не «таблиці в БД», а світ: товари, замовлення, покупці.
Аналогія: спочатку малюємо карту міста (бізнес), потім будуємо будинки (код).

## 2. Bounded context = окрема «кімната»
Каталог і Замовлення — різні кімнати. У кожній свої правила.
Order бере дані про Product з кімнати Catalog, але не лізе змінювати склад напряму хаотично.

## 3. Ubiquitous Language
Усі кажуть однакові слова: Product, Order, Stock.
Як словник команди — щоб «товар» не означав 5 різних речей.

## 4. Фрази
- «DDD починається з бізнесу, а не з фреймворку.»
- «Контекстна карта показує, хто з ким розмовляє.»
- «Класи в domain/ — прототип мови бізнесу в коді.»
