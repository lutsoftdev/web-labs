# Ubiquitous Language — SoftShop

| Термін | Визначення |
|--------|------------|
| Product | Товар у каталозі з ціною і залишком |
| Order | Замовлення покупця (набір позицій) |
| OrderItem | Один рядок у замовленні (товар + кількість) |
| Customer | Покупець, який оформлює Order |
| Stock | Кількість одиниць Product на складі |
| Catalog | Піддомен перегляду й керування товарами |
| Checkout | Процес створення Order з вибраних товарів |
| Payment | (майбутнє) факт оплати Order |

Якщо в Каталозі кажемо «товар», а в Замовленні — теж «товар»,
маємо на увазі один і той самий Product з каталогу.
