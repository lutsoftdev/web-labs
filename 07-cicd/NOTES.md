2. Що таке delivery / CD

## 1. CI = автоперевірка після push
Як учитель, який одразу перевіряє домашню роботу після здачі.
Кроки: checkout → install → test → (build).

## 2. Delivery
Не лише «тести зелені», а й «готовий пакет»:
ми зберігаємо Docker-образ як TAR-артефакт.

## 3. Чому artifact (75), а не GHCR
GHCR — полиця з образами в інтернеті (потрібні права packages:write).
Artifact — файл, прикріплений до конкретного прогону CI. Для 75 балів достатньо.

## 4. Фрази
- «CI ловить помилки до того, як їх побачить викладач/користувач.»
- «Бейдж у README показує статус останнього прогону.»
